# Campus Lost & Found

**Author:** Shahla Tasnim Meem  
**Course:** CSC 311 Advanced Programming

This Spring Boot application lets campus users register, sign in, and report found items. It uses Spring Security for authentication, Thymeleaf for the pages, and H2 to store accounts and reports. Passwords are stored as BCrypt hashes.

## How to run

1. Open the project in IntelliJ as a Maven project.
2. Run `LostfoundApplication.java`.
3. Open `http://localhost:8080`.
4. Register an account, sign in, report an item, and sign out.
